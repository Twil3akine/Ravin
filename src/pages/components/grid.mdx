# Grid

コンポーネントやカードを均等な列で並べるためのレイアウトコンポーネントです。`columns` でデスクトップ時の列数を指定できます。

## Usage

<Tabs labels={["Preview", "Code"]}>
  <Grid columns={3}>
    <NavCard href="/components/button" title="Button" />
    <NavCard href="/components/callout" title="Callout" />
    <NavCard href="/components/tabs" title="Tabs" />
  </Grid>
  <div>
    ```html
    <Grid columns={3}>
      <NavCard href="/components/button" title="Button" />
      <NavCard href="/components/callout" title="Callout" />
      <NavCard href="/components/tabs" title="Tabs" />
    </Grid>
    ```
  </div>
</Tabs>
